# React Background Color Change Application

A simple background change application built with **React**.

---

## Features

- Changes background color on button click.

---

## Tech Stack

- **Frontend:** React, JSX, CSS
- **Tooling:** Vite for development and bundling

---

## Installation

1. Clone the repository:

```bash
git clone https://github.com/raza-jaun-code/background-change-react.git
```

2. Navigate into the project directory:

```bash
cd background-change
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```

Open your browser at http://localhost:5173 (Vite default port).
